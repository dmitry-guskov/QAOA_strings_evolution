# Signed residual continuation: bounded point experiment

Facts: The original retained surrogate is unchanged: after every single backward gate, it applies the same parameter-independent Pauli-weight cutoff 4 and exact terminal-reachability filter as archived pilot v1. Newly dropped signed coefficients enter a separate residual dictionary. That dictionary is propagated exactly through subsequent gates, merges equal Paulis, and is flushed only after one, two, or all complete backward QAOA layers. No secondary numerical threshold or weight mask is applied to the residual. A 100,000-term pre-filter expansion cap causes an explicit abort; all three selected workloads completed below it.

For a window, the residual recurrence is R_next=T_gate(R)+D_gate, while the retained recurrence remains K_next=Pi_gate T_gate(K). At each flush, the contribution to the original surrogate error is the expectation of this residual under the exact remaining suffix. Exact terminal-zero pruning is permitted because every term it removes has identically zero final expectation. The window triangle sum can therefore use either the coefficient l1 norm, or an exact scalar contraction as an oracle diagnostic. The final window has no remaining circuit, so its scalar contraction in |+> is inexpensive and requires no oracle state. The reported hybrid l1 bound uses exact terminal contraction for this final window only.

## Results and costs

On prism6 at the pinned optimized p4 point, the fixed cutoff4 surrogate has error .00944944. One-layer, two-layer, and all-layer windows give exact scalar-oracle absolute sums .07322282, .07216364, and .00944944. Their l1 bounds are 2.95230643, 1.10154172 and .10395932; using exact terminal contraction only in the final window gives 2.93757924, 1.04732578 and .00944944. Therefore only the all-layer continuation reaches the preset .01 target on this accurate-surrogate example. Its peak residual expansion has 2,046 Pauli terms, equal to the exact PP peak, and its retained-plus-residual propagation visits 95,869 input terms versus 69,128 for exact PP. Peak combined post-filter dictionary storage is 2,987 terms versus 2,046 for exact PP. Median scalar times were about .118 seconds for all-layer continuation and .140 seconds for exact PP in this short run, but the operation and storage counts show no representation-size saving; such small timing differences are not a robust algorithmic speedup. The dense-state reference takes about .0017 seconds.

On K3,3 at the pinned optimized p4 point, the original surrogate error is .24457421. All three window oracle bounds agree with that error to numerical tolerance because the window contributions have a common sign. Any correct certificate for this unchanged surrogate must therefore exceed .24. The all-layer residual peaks at 1,056 terms, the same as exact PP, with 52,545 total input visits versus 38,381 for exact PP. Its scalar time is about .055 seconds versus .044 seconds for exact PP; the dense reference is about .00086 seconds.

On cube8 at the pinned optimized p3 point, the original surrogate error is .37682456, and all three oracle bounds again agree with it. The one-layer residual uses 4,339 peak terms and 48,833 total visits versus 15,981 peak terms and 278,890 visits for exact PP, but certifies only the large existing error. Its l1 bound remains 8.779. The two-layer l1 bound worsens to 13.524, showing that longer residual propagation need not monotonically improve a coefficient-l1 certificate: unitary evolution can increase coefficient l1 before cancellation occurs. The all-layer residual has 15,977 peak terms and 298,859 total visits, with roughly the same scalar runtime as exact PP (.441 versus .429 seconds). The dense reference takes about .0031 seconds. Oracle preparation and contraction costs are separately recorded in results.json and cannot be omitted from end-to-end comparisons.

Validation: Each retained energy matches the archived original reference to 1e-10. Each exact PP energy matches an independently constructed dense-state value to the same tolerance. The signed sum of window oracle contributions reconstructs exact-minus-original-surrogate energy to 1e-10. Actual errors are below all reported l1, final-terminal hybrid, and oracle absolute-sum bounds. Timing records have three repeats per non-oracle scalar workload; hardware variation makes operation counts and peak dictionary sizes more informative here. The same scalar propagation kernel, rotation convention, terminal filter and numerical arithmetic are used for retained, exact and sidecar comparisons. The interval/derivative reference is used only to establish identical original-surrogate behavior, not as the timing baseline.

Assessment: This bounded experiment does not support a useful certificate at lower cost than exact evaluation for the tested points. Residual aggregation captures genuine cancellation, but the accurate prism surrogate requires retaining a residual with essentially the full exact Pauli support until the end. The other two original surrogates are themselves inaccurate at cutoff4. These results do not exclude a different window schedule, compressed residual representation, mask, graph, parameter point, or accuracy target. They do justify stopping this particular point-certificate route before adding a more expensive box extension. No box or gradient certificate is claimed here.

## Reproduction

Run python3 -B QAOA_strings_evolution/research/diagnostics/residual/experiment.py . The folder contains pinned inputs.json, the archived reference implementation, the standalone experiment, raw results.json, and provenance.json. Python bytecode writing is disabled, and the experiment writes only its local result file. The code is an exact-arithmetic truncation reference implemented in float64; arithmetic roundoff is outside the analytic certificate.
